# Перелік технічних змін у тексті книги

Зміст не змінювався. Нижче лише технічні виправлення після конвертації з docx.

- Прибрано службове екранування апострофа (\') після конвертації з docx: 1 місць (adminustrii: 1)
- Символ U+0336 (перекреслення), яким у docx набрано тире, замінено на звичайне тире «–»: 5 місць (adminustrii: 2, 1-1-lodovykova-epokha: 3)
